Project Overview

This project is a Unified Beneficiary Search System developed using Power BI to support Call Center and Operations teams in quickly retrieving beneficiary information from a centralized database. The dashboard was designed to allow users to search for a beneficiary using any available identifier, including phone number, mobile number, beneficiary name, national ID, case code, UNHCR file number, or UNHCR card number. Once a match is found, all relevant beneficiary details are displayed instantly in a single interface. The solution streamlines the search process, reduces response time, and eliminates the need to navigate multiple systems, enabling customer service representatives to provide faster and more accurate support.

Data Privacy Notice

All names, phone numbers, national IDs, case codes, organization names, and other sensitive information shown in this project have been replaced with fictional (Dummy) data for demonstration purposes. The original dashboard design and functionality have been preserved while protecting the privacy of the organization and its beneficiaries.

My Role

  • Data cleaning and validation using Microsoft Excel.
  • Identifying and resolving data quality issues.
  • Data transformation using Power Query.
  • Building the data model in Power BI.
  • Designing the unified search interface.
  • Developing an operational dashboard optimized for Call Center users.
  • Improving the user experience by enabling searches through multiple identifiers.

Workflow

  • The project started with a master file containing all registered case codes. The data entry team created family profiles by extracting information from supporting documents such as national ID cards, birth certificates, and other social documents.
  • My role was to clean, validate, and analyze the data using Microsoft Excel, identify and correct data quality issues, then transform the dataset using Power Query before building the data model in Power BI.
  • Based on feedback from the Call Center team, I developed a unified search interface that allows agents to locate a beneficiary using any available information, including Phone Number, Mobile Number, Beneficiary Name, Case Code, National ID, UNHCR File Number, or UNHCR Card Number. Once a match is found, all beneficiary details are displayed instantly in a single view, eliminating the need to search across multiple systems.
